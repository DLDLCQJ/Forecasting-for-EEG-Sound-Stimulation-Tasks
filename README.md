## Our final objective is to predict long term time series using a deep learning method.
Three Key Points: 
- Multivariate time series forecast
- Time dependency of time-series data 
- Features distributions within each time sequence (temporal dynamics)

![image](https://github.com/DLDLCQJ/Forecasting-for-EEG-Sound-Stimulation-Tasks/assets/145650040/f76e7e20-639e-4d2f-a89c-abe67ca18a0f)

We propose a simple RNN model that is based on GRU model, which not only can capture the complex time dependences of those features across time.
